## What to build

This slice builds the "brain" of the formatting system: the `Repertoire::CifraFormatterService`. This service handles the alignment of chords and lyrics, supporting both plain-text (for legacy/console) and structured JSON/HTML (for rich-text copying and PDF/DOCX renderers). We also update the `ClipboardController` to support rich-text (HTML) copying so that "Copiar Cifras" preserves bold formatting.

### Modules to build

#### `Repertoire::CifraFormatterService` (`app/services/repertoire/cifra_formatter_service.rb`)

- **Input:** `content_json` (array of sections, already transposed).
- **Output:** A structured payload containing lines, where each line has "parts" that identify as `chord`, `lyric`, or `label`.

**Formatting Logic:**
- It must handle the padding/alignment logic.
- For each section (except `label` types):
  - Iterate through lines.
  - For each part in a line:
    - If it has a chord, calculate the space needed for the chord vs the lyric.
    - Chords are padded with spaces to match lyric length if lyrics are longer, or vice-versa.
  - Return two strings per line: `chord_line` and `lyric_line`.
- For `label` types:
  - Just return the label text wrapped in brackets (e.g., `[Refrão]`).

**Interface:**
```ruby
# Returns structured data for rich-text/PDF
def self.call(content_json) → { sections: [...] }

# Helper for clipboard HTML
def self.as_html(content_json) → "<pre><b>G</b>   <b>C</b>\nLyric text</pre>"
```

#### `ClipboardController` Update (`app/javascript/controllers/clipboard_controller.js`)

- Add support for `htmlSourceId` or `htmlContent` value.
- Use `navigator.clipboard.write([new ClipboardItem({ 'text/plain': ..., 'text/html': ... })])`.
- This allows pasting bold chords into Word/Docs while falling back to plain text in Notepad.
